# ENA CI Prépa V4

Projet Android destiné à être compilé automatiquement avec GitHub Actions.

Fonctions de démonstration :
- 3 étapes du concours
- cours
- QCM
- examens blancs chronométrés
- progression locale
- préparation à l'oral
- profil
- espace PRO (structure de démonstration)
- lien vers les communiqués officiels de l'ENA

Le contenu fourni est un contenu pédagogique original de démonstration et ne prétend pas être constitué de sujets officiels.
